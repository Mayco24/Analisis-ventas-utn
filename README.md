# Análisis de Ventas UTN

## Integrantes
> Mayco Zapata
> Luis Sosa

## Escenario elegido
Escenario B: Análisis de ventas de una pequeña empresa.

## Descripción del proyecto
Este proyecto analiza datos simples de ventas comerciales. El objetivo es calcular ventas totales, ventas por mes y producto más vendido.

## Estructura del repositorio
- datos/: contiene el archivo ventas.csv.
- scripts/: contiene el archivo analisis_ventas.py.
- resultados/: carpeta destinada a guardar resultados.
- README.md: documentación del proyecto.
- .gitignore: archivo para excluir elementos innecesarios.

## Herramientas utilizadas
- Git
- GitHub
- Jira
- Google Colab
- Python

## Cómo ejecutar el proyecto
Desde Google Colab, dentro de la carpeta del repositorio, ejecutar:

python scripts/analisis_ventas.py
